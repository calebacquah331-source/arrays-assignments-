1. Introduction

An array is a data structure used to store multiple values under one variable name. Each value occupies a position called an index, allowing a program to access and manipulate individual elements. Traditional arrays in many programming languages store elements of the same data type. Python lists, used in this project, are more flexible.

For example:

marks = [75, 80, 65, 90, 85]

The marks list stores five values. In Python, indexing starts at 0, so marks[0] is 75.

2. Real-World Applications That Use Arrays

Student Management Systems

Arrays store students' marks, attendance records, and identification numbers. They help calculate averages, find the highest score, and process many student records.

Supermarket and Inventory Systems

Arrays can store product prices, quantities, and stock codes. Programs can search for items, update quantities, and calculate stock value.

Hospital Management Systems

Arrays can organize patient waiting lists, appointment times, and sets of vital-sign measurements. Real hospital systems also use databases and other data structures.

Weather Forecasting Systems

Arrays store temperature, rainfall, and humidity readings over time. Programs can calculate averages, identify trends, and compare weather conditions.

Video Games

Arrays store player scores, game-board positions, health values, and coordinates. They help games manage multiple objects and update their states.

Banking Systems

Arrays can hold transaction amounts for calculations, daily summaries, and reports. Production banking systems also rely on databases and other structures for secure, persistent records.

3. Why Arrays Are Necessary

  1. Organizing data: Store many related values under one variable name.
  2. Easy access: Access individual elements using their indexes.
  3. Efficient processing: Use loops to process many values without repeating statements.
  4. Easy calculations: Calculate totals, averages, minimums, and maximums.
  5. Reduced repetition: Use one structure instead of creating many separate variables.
  6. Updating data: Change stored elements when information changes.
Limitation: Traditional fixed-size arrays have a fixed capacity, and some languages require all elements to have the same type. Python lists can grow and shrink dynamically.

5. Python Source Code

This program can be run in Visual Studio Code with Python installed. The two lists use matching indexes so that each student's name stays associated with their mark.

# STUDENT MARKS MANAGEMENT SYSTEM
# Arrays are represented by Python lists.

student_names = []
student_marks = []


def add_student():
    name = input("Enter student name: ").strip()

    if not name:
        print("Name cannot be empty.")
        return

    try:
        mark = float(input("Enter student's mark (0-100): "))

        if mark < 0 or mark > 100:
            print("Mark must be between 0 and 100.")
            return

        student_names.append(name)
        student_marks.append(mark)
        print("Student added successfully!")

    except ValueError:
        print("Please enter a valid number.")


def display_students():
    if not student_names:
        print("No student records available.")
        return

    print("\\n--- STUDENT RECORDS ---")
    for i in range(len(student_names)):
        print(
            f"{i + 1}. {student_names[i]} "
            f"- {student_marks[i]}/100"
        )


def calculate_average():
    if not student_marks:
        print("No marks available.")
        return

    average = sum(student_marks) / len(student_marks)
    print(f"Average mark: {average:.2f}")


def find_top_student():
    if not student_marks:
        print("No marks available.")
        return

    highest_index = student_marks.index(max(student_marks))
    print("Top student:", student_names[highest_index])
    print("Highest mark:", student_marks[highest_index])


while True:
    print("\\n===== STUDENT MANAGEMENT SYSTEM =====")
    print("1. Add student")
    print("2. Display students")
    print("3. Calculate average mark")
    print("4. Find top student")
    print("5. Exit")

    choice = input("Choose an option: ")

    if choice == "1":
        add_student()
    elif choice == "2":
        display_students()
    elif choice == "3":
        calculate_average()
    elif choice == "4":
        find_top_student()
    elif choice == "5":
        print("Thank you for using the system!")
        break
    else:
        print("Invalid choice. Please try again.")
