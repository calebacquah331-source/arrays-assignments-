# Real-World Applications of Arrays

This repository contains a GitHub Pages website for an assignment on real-world applications of arrays and a Python Student Marks Management System.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `student_marks.py`, and this `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. The URL will be shown on the Pages settings screen.

The website is static HTML. The Python program is provided as a downloadable source file and runs locally with Python; GitHub Pages does not execute Python server-side.
